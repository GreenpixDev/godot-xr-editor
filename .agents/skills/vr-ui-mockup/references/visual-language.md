# Визуальный язык макетов

Числа взяты из кода на 2026-10-21. Перед работой проверь, что константы на месте: `grep -n "ROW_HEIGHT\|CARD_WIDTH\|COLORS\|CARD_PALETTE" addons/xr_editor/logic_graph/blueprint_canvas.gd` и `grep -n "WINDOW_SIZE\|COMPACT_SIZE\|PIXEL_SIZE" addons/xr_editor/ui/panels.gd`.

## Размеры (метры)

| Что | Значение | Откуда |
|---|---|---|
| Ширина карточки | 0,26 | `CARD_WIDTH`, blueprint_canvas.gd |
| Высота карточки | 0,08 + строк × 0,045 | `ROW_HEIGHT` |
| Центр первой строки от верха | 0,064 | `_add_port` |
| Порт | радиус 0,010, центр в 0,014 от края | `PORT_RADIUS` |
| Толщина «бруска» (Cuboid) | 0,03 | `CUBOID_DEPTH` |
| Окно вкладки | 480 × 600 точек × 0,0009 = 0,43 × 0,54 | `WINDOW_SIZE`, `WINDOW_PIXEL_SIZE`, panels.gd |
| Окно на руке | 500 × 340 × 0,0005 = 0,25 × 0,17 | `COMPACT_SIZE` |
| Расстояние окна от головы | 0,7, ниже глаз на 0,15 | `WINDOW_DISTANCE`, `WINDOW_DROP` |
| Ячейка Objects | 120 × 130 точек, 3 в ряд | objects_tab.gd |
| Миниатюра объекта | масштаб 1:30 | `MINIATURE_SCALE`, palette.gd |
| Голова | 1,6 над полом | для камеры макета |

В 2D-макете одна единица SVG — 0,26 / 210 м по ширине. Строки там сжаты до 27 единиц ради читаемости, поэтому вертикаль в 2D не в масштабе — так и скажи, если спросят.

## Цвета

Порты по типу (`COLORS`): Exec `#eeeeee`, Value `#63c6ea`, Bool `#e8879b`, Int/Float `#7be5b3`, Text `#e5b57b`, Vector `#89adff`, Object `#b991eb`, Color `#f2d878`.

Лицо карточки по группе (`CARD_PALETTE`, `CARD_GROUPS`): события `#174479`, свойства и движение `#155947`, поток `#553478`, значения и переменные `#323e73`, звук `#785016`, анимация `#743351`.

Окна Meta: фон `#1d2026` (полупрозрачные — 62 %), поля `#2b2f38`, текст `#f1f3f7`, подписи `#a9b0bf`. Сцена: небо `#1c2232` → `#121722`, пол `#1b202b` → `#0b0e14`, затемнение `#04060a` с прозрачностью 0,42. Оси: X `#ff6b6b`, Y `#7be5b3`, Z `#89adff`.

Метки идей на страницах: C (фишки) — янтарный, D (сцена) — фиолетовый, F (форма графа) — зелёный. Для новых идей заводи свою букву и цвет из той же гаммы.

## Анатомия

- **Карточка**: заголовок «Title · id» по центру, корзина слева, плюс справа. Входы слева, выходы справа, подпись рядом с портом. Выбранная — белая рамка.
- **Член объекта на карточке** (при «Цели = Сцена»): «Target · light_color», имя — фиолетовым моноширинным.
- **Шайба**: пилюля в прорези справа в строке, рамка цвета типа, слева значок типа, затем значение.
- **Деталь**: брусок со скруглением 5, левее края карточки; хвост входит в порт. Круглый хвост — в порт, квадратный — в гнездо без порта. Зазор между карточками около 7 см.
- **Квадратное гнездо**: параметр без порта (решается при сборке: Wait, Policy).
- **Лепесток**: пилюля с фиолетовой рамкой; выбранный — белая рамка, несовместимый — тусклый. Лепестки никогда не висят сами по себе: веер растёт из белой точки на объекте, к ней идёт белая ножка, лепестки собраны фиолетовым корешком. Веер стоит на стороне, обращённой к пользователю, а не в промежутке между объектами — иначе непонятно, чей он. Объект, чей веер открыт, обведён белым, как при выделении. Невидимые дети — группами на ножке ближайшего 3D-предка, над группой имя типа ноды.
- **Лепесток выбранного члена**: после выбора веер сворачивается в один лепесток на белой ножке из точки выбора на объекте, на стороне к пользователю; провод Target приходит к лепестку (D-053).
- **Ящик переменной**: брусок цвета типа; над ним «имя тип», на передней стенке корзина слева и гнездо со значением при запуске справа. Корзина тусклая, пока к ящику идут провода: занятую переменную удалить нельзя.
- **Фишка под проводом**: провод в порт не удаляет фишку, а прячет — шайба бледнеет в прорези; удалить фишку значит сбросить её к значению по умолчанию.
- **Окно**: без заголовка; под ним пилюля Control Bar с иконкой, названием, булавкой и ×.
- **Контроллер**: кольцо и рукоять; луч белый, на конце белая точка.

## Термины

Окно, панель, привязка к ригу, угловые ручки, Control Bar, лаунчер — как в `docs/vr_ui.md`. Фишка, шайба, деталь, гнездо, лепесток, лоток, ящик — термины концепта параметров в графе (страница «Параметры Blueprints в графе»).
