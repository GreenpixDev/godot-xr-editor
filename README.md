# XR Editor для Godot

VR-редактор сцен для Godot 4.7: собрать сцену, оживить её логикой и протестировать, не снимая шлем. Это EditorPlugin, а не отдельное приложение. VR-вид и настольный редактор работают с одним и тем же документом, поэтому любое действие в шлеме сразу видно на столе и отменяется с клавиатуры.

Проект — дипломная работа. Помимо прототипа, она измеряет, в каких задачах VR-редактор быстрее и точнее настольного, а в каких проигрывает.

**Статус:** реализованы базовые инструменты компоновки, play-mode и панели. Добавлен первый прототип Blueprints в VR поверх самостоятельного 2D-аддона. Его ввод проверен в headless-редакторе, проверка в шлеме ещё предстоит.

## Требования

- Godot **4.7.x** (разработка на 4.7.2). Другие версии не поддерживаются до конца исследования.
- PCVR-шлем с OpenXR-runtime (SteamVR или Meta Link).
- Для сборки нативной части (Windows): Visual Studio 2026 с нагрузкой «Разработка классических приложений на C++» (MSVC, Windows SDK, CMake).

## Сборка и запуск

Нативная часть (`gdextension/`) даёт редактору ввод с контроллеров. Её нужно собрать один раз после клонирования и после каждого изменения C++, при закрытом редакторе:

```bash
git submodule update --init
scripts/build_gdextension.sh
```

Обычный редактор и редактор с VR-видом (шлем подключён до запуска):

```bash
godot --path . --editor
godot --path . --editor --xr-mode on
```

Плагин включён в `project.godot`. Корень репозитория — хост-проект для разработки, сам плагин лежит в `addons/xr_editor/`.

Для этой версии XR Editor нужны обе папки: `addons/xr_editor/` и `addons/blueprints/`. В репозитории оба плагина включены. Самостоятельный Blueprints 2D можно устанавливать отдельно, без XR и нативной библиотеки.

Проверка без шлема (все скрипты загружаются, плагин стартует в headless-редакторе):

```bash
scripts/check.sh
```
