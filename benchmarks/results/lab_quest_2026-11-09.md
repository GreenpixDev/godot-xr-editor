# Quest 2: GPU по видам и кривые роста (D-157, 2026-11-09)

Quest 2, Godot 4.7.2 (сборка Meta), редактор в шлеме, фовеация 3, остальное как в D-155. BlueCube — ветка master (27 блоков на шаге `open`: вызовов 385–391 по VrApi, в виде 351–360). Граф и сцена в кадре целиком: вид считает `XREGraphLab._frame_view` по границам геометрии, проверено снимками камеры в позе головы (`--xre-graph-lab-pose`).

Прогоны:
- База GPU с `ovrgpuprofiler -e` (подробный режим, ~10 % к GPU): `logs/quest_2026-11-09T20-16-04_run.log`, трассы `_gpu_NN_<шаг>.txt` рядом. Таблица 1.
- Кривые роста, без профайлера: `logs/quest_2026-11-09T20-36-54.log`. Таблица 2.
- Первые прогоны того же дня (граф за спиной пользователя, сцена вне кадра) в выводах не используются.

«GPU» в таблицах видов — `viewport_get_measured_render_time_gpu` вида `XRESession/XREViewport` (оба глаза), мс за кадр. Compatibility на Android время GPU не пишет, там 0.

- CPU рендера вида (`render CPU`) линеен и одинаков для графа и сцены: около 2,9–3,3 мкс на вызов (граф 500 блоков: 16,3 мс; сцена 20k: 45,6 мс).

- Перестройка графа (`rebuilt`): 100 блоков 524 мс, 250 — 1226 мс, 500 — 2936 мс (около 5 мс на блок); BlueCube из 27 блоков 434 мс при открытии.

**Пол GPU.** `closed_empty` (нет ни графа, ни сцены, лёгкий интерфейс) всё равно стоит 4,45 мс в виде глаза (3,65 мс по `ovrgpuprofiler` на поверхности 1440×1584): это нижняя граница, откуда она, не разобрано. `closed` — 7,3–7,8 мс; из них сцена и интерфейс около 3 мс.

**Проверка профайлером (таблица 1, подробный режим).** Поверхность глаз 1440×1584 по `ovrgpuprofiler -t1 -v`: closed 7,7 мс, open 12,7, open_big2 17,7, closed_empty 3,65 — совпадает с измерением движка (7,8 / 12,4 / 17,6 / 4,45), то есть собственное измерение времени вида на Mobile можно брать за GPU. Compatibility (там своё измерение не пишет): closed 6,9, open 10,6, open_big2 12,5 мс. Compatibility на открытом графе экономит около 2 мс GPU и около 9 мс CPU вида (render CPU 3,3 против 1,2 мс у Mobile — он больше, но App меньше: 7,9 против 14,3).

**Что убирает вклад (таблица 1, Mobile, GPU вида глаза).**
- `open_all_off` (все виды объектов холста скрыты) 7,15 мс: весь прирост открытого графа — 5,2 мс — приходится на его геометрию.
- `open_ui_off` 12,15 (−0,2), `open_dimmer_off` 12,26, `open_root_off` 12,54: окно редактора, затемнение и интерфейс на GPU вида почти не стоят (в `App` `root_off` даёт −3 мс).
- `open_lean` 11,56 (−0,8) и `closed_lean` 6,19 (−1,4): облегчённый интерфейс.
- `closed_vr_off` 7,01 (−0,6) и `closed_scene_off` 6,30 (−1,5).
